# Test Planning Skill

## Purpose
Create structured test plans that map requirements to categories, risk areas, and scenarios.

## Use when
- The repository, requirement, and impact areas are understood.
- The system needs a plan before test generation or automation.

## Outputs
- Test plan ID
- Scope and out-of-scope areas
- Positive/negative/boundary/regression scenarios
- Environment and data needs
- Risk and automation suitability

## Rules
- Base it on evidence from the requirement and repository.
- Keep the plan reusable across project types.
