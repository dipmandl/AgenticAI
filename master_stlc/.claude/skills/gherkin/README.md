# Gherkin Skill

## Purpose
Standardize human-readable test case authoring using Gherkin when practical.

## Use when
- Creating manual validation cases
- Drafting acceptance scenarios for review
- Aligning tests to business requirements

## Structure
- Feature
- Scenario
- Given / When / Then
- Optional And / But blocks

## Rules
- Use stable IDs and tags.
- Keep scenarios traceable to requirement IDs.
- Avoid unnecessary tags.
